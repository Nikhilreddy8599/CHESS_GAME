# ♟️ Java Chess Game

A fully functional **Chess game built using Java Swing**, implementing core game mechanics along with advanced rules and edge cases.

---

## 🚀 Overview

This project is a desktop-based Chess game where two players can play against each other on the same system. It focuses on implementing real-world chess rules while maintaining a simple and interactive GUI.

Being a chess enthusiast, this project helped me translate my understanding of the game into code, making development both challenging and enjoyable.

---

## 🎯 Features

- Complete movement logic for all pieces  
- Turn-based gameplay (White vs Black)  
- Check, Checkmate & Stalemate detection  
- Castling support  
- Pawn Promotion with user selection  
- Draw conditions:
  - 50-move rule  
  - Insufficient material  
- Highlighting legal moves and checks
